# Wordly

เว็บเรียนภาษาอังกฤษสำหรับผู้ใช้ภาษาไทย มีแฟลชการ์ด 400 คำและวลีใน 8 หมวด หมวดละ 50 รายการ ออกแบบให้ใช้ได้บนมือถือ แท็บเล็ต และคอมพิวเตอร์

## เปิดใช้งาน

เปิด `index.html` โดยตรงได้ หรือใช้ Node.js รัน:

```sh
npm.cmd run dev
```

แล้วเข้า `http://localhost:4173` ใช้ `npm start` ได้เช่นกัน ไม่ต้องติดตั้ง dependency เพื่อใช้งานแอปหรือเปิดเซิร์ฟเวอร์ ตัวเว็บใช้ HTML, CSS และ JavaScript โดยไม่มีขั้นตอน build เมื่อแก้ไฟล์ให้รีเฟรชเบราว์เซอร์เพื่อดูผล

ฟอนต์ DM Sans และ Noto Sans Thai เก็บไว้ใน `assets/fonts/` พร้อมใบอนุญาต SIL Open Font License ข้อมูลคำศัพท์ ฟอนต์ และการฝึกไม่ต้องเรียก API ภายนอก เสียงอ่านใช้ Web Speech API และขึ้นอยู่กับเสียงภาษาอังกฤษที่อุปกรณ์รองรับ บางเสียงอาจต้องใช้อินเทอร์เน็ต

## วิธีใช้งาน

- **แนะนำ / แจ้งปัญหา:** ผู้ใช้เลือกประเภทความคิดเห็น เขียนข้อความได้สูงสุด 2,000 ตัวอักษร และกรอกชื่อเล่นได้ตามต้องการ ข้อความส่งถึงเซิร์ฟเวอร์โดยไม่เผยแพร่ต่อผู้ใช้คนอื่น หากส่งไม่สำเร็จจะเก็บข้อความไว้ในฟอร์มให้ลองใหม่

### อ่านข้อเสนอแนะจากผู้ใช้

เปิดเว็บผ่าน `npm.cmd start` เพื่อใช้ระบบส่งความคิดเห็น การเปิด `index.html` โดยตรงหรือโฮสต์เฉพาะไฟล์ static จะส่งไม่ได้ ต้องรัน Node server นี้ด้วย `/api/feedback` บนเว็บไซต์เดียวกัน ข้อความบันทึกใน `data/feedback.jsonl` บนเครื่องเซิร์ฟเวอร์ โดยสร้างไฟล์เมื่อได้รับข้อความแรก ไม่มี API อ่านข้อความสาธารณะ

ผู้ดูแลเปิดอ่านไฟล์ได้ หรือใช้ PowerShell บนเครื่องเซิร์ฟเวอร์:

```powershell
Get-Content -Encoding utf8 data/feedback.jsonl | ForEach-Object { $_ | ConvertFrom-Json } | Format-List createdAt, type, name, message
```

หากนำไปโฮสต์ ให้เก็บโฟลเดอร์ `data` ในพื้นที่ดิสก์ถาวรและสำรองข้อมูลไว้ ระบบนี้เก็บข้อความไว้ที่เซิร์ฟเวอร์เดียว ยังไม่มีหน้าจัดการหรือการแจ้งเตือนทางอีเมล ข้อมูลการเรียนยังเก็บในเบราว์เซอร์ตามเดิม

### การฝึกภาษา

- **ฝึกคำศัพท์:** สุ่มจาก 400 รายการทั้งหมด หรือเลือกหมวดจาก dropdown/การ์ดหมวดหมู่
- **คำใบ้:** แสดงเฉพาะเมื่อกด ไม่เปิดเฉลยไปพร้อมกัน
- **พิมพ์คำแปลไทย:** พิมพ์แล้วกด Enter หรือ “ตรวจคำตอบ” รับได้หลายคำแปลที่กำหนดไว้ตามบริบทหมวด คำตอบที่ตรงบันทึกเป็น “จำได้แล้ว” ส่วนที่ยังไม่ตรงเก็บไว้ทบทวน แสดงผลพร้อมรายการคำแปลก่อนกดไปคำถัดไป
- **เฉลย:** แสดงคำแปลไทยและตัวอย่างการใช้ แล้วเลือก “จำได้แล้ว” หรือ “ยังจำไม่ได้” เพื่อบันทึกและสุ่มคำถัดไป
- **ทบทวน:** สุ่มเฉพาะคำที่สถานะล่าสุดเป็น “ยังจำไม่ได้” ในหมวดที่เลือก หากไม่มีคำ จะแสดงปุ่มกลับไปฝึกทุกคำ
- **ข้าม:** เปลี่ยนคำโดยไม่บันทึกผล ไม่เพิ่มจำนวนครั้งที่ฝึก
- **คลังคำศัพท์:** ค้นอังกฤษ/ไทย กรองหมวดและสถานะ แบ่งหน้า 20 รายการ และเลือกคำมาเริ่มฝึกได้
- **ความคืบหน้า:** จำนวนคำที่จำได้/ต้องทบทวน เป้าหมาย 20 ครั้งต่อวัน ประวัติ 7 วัน และจำนวนวันที่ฝึกต่อเนื่อง

คีย์ลัดบนหน้าฝึก: `H` ดูคำใบ้, `Space` เฉลย, `1` ยังจำไม่ได้, `2` จำได้แล้ว, `→` ข้าม โดยไม่รบกวนการพิมพ์ในช่องค้นหาหรือการเลือกหมวด และ Space บนปุ่มจะทำงานตามปุ่มนั้น

จำนวนครั้งต่อวันนับการส่งคำแปล หรือการกดประเมินหลังเปิดเฉลย ครั้งละหนึ่งผล รวมการฝึกคำเดิมซ้ำ ช่องว่างเปล่า การส่งซ้ำในการ์ดเดิม และปุ่มคำถัดไปไม่นับเพิ่ม จำนวนคำที่จำได้อิงสถานะล่าสุดของแต่ละคำ จึงไม่เพิ่มซ้ำเมื่อประเมินคำเดิมหลายครั้ง วันที่ใช้เวลาท้องถิ่นของอุปกรณ์

การตรวจคำตอบครอบคลุมทั้ง 400 คำใน 8 หมวด ใช้คำแปลหลักใน `src/data/translations.js` และคำอธิบายสำนวนทั่วไปเพิ่มเติม 1,265 แบบใน `src/data/grading.js` พร้อมคำตอบบางส่วนทุกคำ รองรับคำทับศัพท์และรูปสะกดที่กำหนดไว้ เช่น “โน๊ตบุ๊ค”, “เซิฟเวอร์”, “ฟังก์ชั่น” และรูปประโยคอธิบายหน้าที่สำหรับ 108 คำ เช่น “เป็นอุปกรณ์ที่ใช้รับเสียงเข้าคอมพิวเตอร์” และ “โปรแกรมสำหรับเปิดเว็บไซต์” กฎจับทั้งข้อความ ไม่ใช้เพียงการเจอคำสำคัญที่ใดก็ได้ในคำตอบ

- **ถูก: 1/1** — ความหมายตรงกับคำและบริบท บันทึกเป็นจำได้แล้ว
- **เข้าใจบางส่วน: 0.5/1** — จับประเด็นได้แต่ไม่ครบ อธิบายจุดที่ขาดและเก็บไว้ทบทวน เช่น Brute force ตอบ “เดารหัส” หรือ “สุ่มรหัสผ่าน”
- **ยังไม่ตรงกับคำแปลที่รองรับ: 0/1** — ยังยืนยันความหมายไม่ได้ เก็บไว้ทบทวน คำอย่าง “รหัส”, “สุ่ม” เดี่ยว ๆ ไม่ได้คะแนน

รองรับช่องว่าง Unicode สระ “ำ” ทั้งรูปปกติและรูปแยกอักขระ คำขึ้นต้น “หมายถึง/คือ/เป็น” คำลงท้ายสุภาพ และการตอบหลายความหมายด้วยจุลภาคหรือ `/` โดยใช้คะแนนต่ำสุดของทุกความหมาย หากมีส่วนที่ไม่เกี่ยวข้องจะไม่ได้คะแนน ผลคะแนนล่าสุดบันทึกใน record ของคำนั้นและแสดงครึ่งคะแนนในคลังคำศัพท์ จำนวนครั้งฝึกยังนับครั้งละ 1 ไม่ใช่คะแนนสะสม การประเมินตัวเองหลังดูเฉลยไม่มีคะแนนทดสอบ ระบบนี้ยังเป็นเกณฑ์ที่เตรียมไว้ ไม่ใช่ AI ตรวจความหมายอิสระ จึงไม่รับประกันว่าจะเข้าใจทุกประโยคที่เขียนได้ แม้จะมีเกณฑ์ครบทุกคำแล้ว

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์และ origin ที่เปิดใช้ ไม่มีบัญชีหรือการซิงก์ข้ามเครื่อง การเปิดผ่านไฟล์กับ localhost อาจเห็นข้อมูลคนละชุด หากเบราว์เซอร์ปิดกั้น storage ยังฝึกในรอบปัจจุบันได้ และแสดงสถานะว่าไม่สามารถบันทึกถาวร

## โครงสร้างไฟล์

```text
index.html                       จุดเริ่มต้นและลำดับการโหลดสคริปต์
assets/favicon.svg               ไอคอน Wordly
src/
  app.js                         ประกอบหน้า เชื่อม callback และจัดการ navigation
  components/
    Header.js                    เมนูนำทาง
    Flashcard.js                 การ์ด คำใบ้ เฉลย เสียงอ่าน และการประเมิน
    CategoryGrid.js              การเลือกหมวดและความคืบหน้ารายหมวด
    Library.js                   ค้นหา กรอง และแบ่งหน้าคลังคำศัพท์
    Progress.js                  เป้าหมายรายวันและสถิติ
  data/
    categories.js                Metadata และตัวอ่านแถวข้อมูล
    office.js, computer.js, dev.js, cyber.js
    hotel.js, restaurant.js, daily.js, travel.js
    translations.js              คำแปลและคำเทียบที่รับได้ของทั้ง 400 รายการ
    grading.js                   สำนวนทั่วไป เกณฑ์ครึ่งคะแนนครบ 400 คำ และรูปประโยคอธิบายหน้าที่
  lib/
    study.js                     ฟังก์ชันสุ่ม กรอง นับผล และจัดการวัน
    answers.js                   ปรับรูปแบบและตรวจคำตอบภาษาไทย
    storage.js                   ตรวจและบันทึกความคืบหน้า
    icons.js                     SVG icons
  styles/main.css                รูปแบบ responsive และ reduced motion
scripts/serve.cjs                 Static server สำหรับใช้งานในเครื่อง
tests/study.test.cjs              ทดสอบข้อมูลและ logic ด้วย Node.js
tests/browser.cjs                ทดสอบ flow จริงด้วย Playwright
VOCABULARY.md                    แนวทางดูแลข้อมูลและแหล่งอ่านเพิ่มเติม
```

Component รับ callback และคืน DOM พร้อมเมธอดอัปเดต โดยใช้ namespace `window.EngVocab` และสคริปต์ `defer` เพื่อรองรับการเปิดไฟล์โดยตรง แยก logic การเรียนกับ storage เพื่อเพิ่มระบบเรียนแบบอื่นหรือ backend ในอนาคต

## การตรวจสอบ

```sh
npm test
npm install
npx playwright install chromium
npm run test:browser
```

ทดสอบ logic ได้โดยไม่ติดตั้งแพ็กเกจ ส่วน browser test ใช้ Playwright หากมี Chrome ในเครื่อง ใช้ PowerShell: `$env:BROWSER_CHANNEL = 'chrome'` ก่อนรัน โดยไม่ต้องดาวน์โหลด Chromium เพิ่ม กำหนด `TEST_URL` ได้หากต้องการทดสอบผ่าน localhost ค่าเริ่มต้นทดสอบ `index.html` ผ่าน file URL

Browser test ใช้ browser context ใหม่ ตรวจคำใบ้/เฉลย การประเมิน การทบทวน การคืนข้อมูลเมื่อ reload การกรองทุกหมวด คีย์ลัด การค้นหา การแบ่งหน้า ข้อมูลเสียหาย และการล้นจอที่ความกว้าง 320–1440px บันทึกภาพไว้ใน `artifacts/`
